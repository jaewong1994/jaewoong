## 1. 6월 28번 — 카드 뒤집기(숫자 조건 집합 뒤집기), 4회 뒤 모두 앞면

- 상태: 뒷면 카드의 집합. 초기 {1, 6}.
- 시행: 눈 k가 홀수면 k 이하, 짝수면 k 이상을 뒤집는다. 뒤집는 집합 — 1:{1} · 3:{1,2,3} · 5:{1,…,5} · 2:{2,…,6} · 4:{4,5,6} · 6:{6}.
- **핵심 판단 1 (불변량 번역):** 카드마다 "뒤집힌 횟수의 홀짝"만 최종 면을 정한다. 카드 1·6은 홀수 번, 2·3·4·5는 짝수 번. 카드 2와 3, 카드 4와 5는 같은 눈에 뒤집히므로 조건이 겹친다(독립 제약 4개로 압축).
- **핵심 판단 2 (횟수 벡터 → 배열):** 눈 1~6이 나온 횟수 (n₁,…,n₆), 합 4, 홀짝 조건 4개를 만족하는 벡터를 나열하고 각 벡터의 배열 수(같은 것이 있는 순열)를 더한다. 160/1296 = 10/81.
- 조건의 역할: 초기 뒷면 집합 → 어느 카드가 홀수 번이어야 하는지(목표 홀짝 벡터). 뒤집기 규칙 → 눈별 뒤집기 집합(선형 구조). 시행 횟수 4 → 벡터 합. "모두 앞면" → 목표 상태 하나(여사건·조건부 없음).
- 난도 원천: 상태를 홀짝 벡터로 압축하는 번역, 겹치는 카드 묶기, 횟수 벡터 열거의 완전성. 계산은 작다.
- 변형 축: ① 뒤집기 집합의 구조(약수·배수·구간·보수) ② 초기 상태와 목표 상태(모두 앞면 / 특정 집합 / 앞면 개수) ③ 조건부 질문(최종 상태가 주어졌을 때 특정 회차의 눈) ④ 시행 횟수 3·5 ⑤ 주사위 대신 동전·카드 추출로 눈의 확률을 비균등하게.

## 2. 9월 28번 — 카드 자리 바꾸기(인접 교환), 4회 뒤 원상태일 때 3번째 눈이 6일 확률

- 상태: 여섯 자리의 문자열(같은 문자는 구별하지 않음). 초기 AAABBB. 상태 공간은 20개.
- 시행: k≤5 → k, k+1 자리 교환, 6 → 유지. **같은 문자끼리 교환하면 상태가 바뀌지 않으므로** 눈의 일부는 '효과 없음'이다. 초기 상태에서 효과 있는 눈은 3 하나뿐, AABABB 에서는 2·3·4 셋.
- **핵심 판단 1 (상태 압축):** 눈을 '상태를 바꾸는 눈'과 '그대로 두는 눈'으로 나눈다. 그대로 두는 눈의 개수가 상태마다 다르다(5개·3개 …). 이 가짓수(가중치)를 보존해야 한다(KG-A25 "상태 압축 뒤 가중치 보존").
- **핵심 판단 2 (되돌아오기 = 짝수 유효 이동):** 효과 있는 교환은 'B가 A보다 앞에 있는 쌍의 수'를 ±1 바꾸므로 원상태로 돌아오려면 유효 이동이 0·2·4번이어야 한다. 0번: 5⁴=625, 2번: 나갔다가 같은 눈 3으로 돌아오는 경우를 유효 이동 위치별로 가중(114), 4번: 3개 경로(3). 분모 742.
- **핵심 판단 3 (조건부확률의 분자):** 같은 분류를 유지한 채 '3번째 눈 = 6'을 더한다(6은 모든 상태에서 효과 없음). 125+13+0 = 138. 답 138/742 = 69/371.
- 조건의 역할: 같은 문자 3+3 → 효과 없는 눈의 가중치. k=6 유지 → 모든 상태에서 공통 항등 눈(분자 사건의 소재). 4회 → 유효 이동 0·2·4. 원상태 조건 → 분모 사건. "3번째 눈이 6" → 조건부 분자.
- 난도 원천: 효과 없는 눈을 세는 가중치, 유효 이동의 홀짝(되돌아오기), 2회 유효 이동의 위치별 가중 합, 4회 유효 경로의 전수. 계산은 작으나 누락이 쉽다.
- 변형 축: ① 문자 구성(AABB·AAABB·ABC) ② 교환 규칙(k와 k+1 / k와 7−k / 순환) ③ 분모 사건(원상태 / 특정 상태 / 앞 3자리 동일) ④ 분자 사건(특정 회차 눈·유효 이동 횟수·눈의 합) ⑤ 뒤집기와 교환의 결합.

## 3. 9월 30번 — 표본평균의 분포에서 Σk²P 읽기

- 모집단: 0, 1, 2 균등. 복원추출 5회, X̄ = S/5(S = 합, 0~10).
- **핵심 판단 1 (합의 형태를 적률로 번역):** Σ_{k=1}^{10} k²·P(X̄ = k/5) = Σ k² P(S = k) = E(S²). (k=0 항은 0이라 1부터 더해도 같다.)
- **핵심 판단 2 (분산 공식으로 계산):** E(S²) = V(S) + {E(S)}². 모평균 m=1, 모분산 σ²=2/3. E(S)=5, V(S)=5·(2/3)=10/3 (또는 V(X̄)=σ²/5 → V(S)=25·V(X̄)). a=85/3, 6a=170.
- 조건의 역할: 모집단 값 → m, σ². 복원추출 5회 → 독립, V(S)=nσ². X̄ = S/5 → k/5 와 k 의 대응. Σ의 범위 1~10 → S 의 전 범위(0 포함 무해). "6a" → 자연수 답.
- 난도 원천: 낯선 Σ 식을 E(S²)로 읽는 번역 한 번. 이후는 공식. 실제로는 중간 난도. 최고난도로 올리려면 번역 뒤에 **미지 모수·조건부·분포 결정**을 결합해야 한다(KG-A18 은닉·역방향).
- 변형 축: ① 모집단 비균등·미지 확률 ② 묻는 합 Σ(k−c)²P, Σk(k−1)P, Σ(2k−5)²P ③ 역방향: 합의 값에서 n 또는 모집단 구성 결정 ④ 조건부: 첫 추출 결과가 주어진 뒤의 적률 ⑤ 비복원 동시 추출과의 대비 ⑥ 이항분포와의 결합(X~B(n,p)의 E(X²)) ⑦ 두 통계량의 결합(Σ k·P(X̄=k/n)·… ).

## 4. 2025 수능 28번 — 끝값이 가운데의 범위를 정하는 함수 개수

- f: X→X, X={1,…,6}. (가) f(1)f(6)이 6의 약수. (나) 2f(1) ≤ f(2) ≤ f(3) ≤ f(4) ≤ f(5) ≤ 2f(6).
- **핵심 판단 1 (끝값 쌍 열거):** (가)에서 (f(1), f(6)) ∈ {(1,1),(1,2),(1,3),(1,6),(2,1),(2,3),(3,1),(3,2),(6,1)} 9쌍.
- **핵심 판단 2 (가운데는 중복조합):** 가운데 네 값은 구간 [2f(1), 2f(6)] ∩ {1,…,6} 에서 비감소 4개 선택 → 길이 L이면 _L H_4. 구간이 비면 0.
- 합: (1,1): [2,2] → 1 · (1,2): [2,4] → ₃H₄=15 · (1,3): [2,6] → ₅H₄=70 · (1,6): [2,6] → 70 · (2,1): [4,2] → 0 · (2,3): [4,6] → ₃H₄=15 · (3,1): 0 · (3,2): [6,4] → 0 · (6,1): 0 → 1+15+70+70+15 = 171.
- 조건의 역할: (가) → 끝값 후보의 유한 열거(약수 구조). (나) 양 끝 계수 2 → 가운데 범위를 끝값의 2배로 밀어 올려/내려 구간이 비는 경우를 만든다. 비감소 → 중복조합.
- 난도 원천: 두 조건을 '끝값이 범위를 정한다'로 결합, 구간이 X 밖으로 나가거나 비는 경계 처리, 중복조합의 정확한 적용. 전수 9쌍 중 4쌍이 0.
- 변형 축: ① 끝값 조건(곱·합·차·약수·배수·f(f(1))) ② 가운데 조건(비감소·부분 엄격·간격 ≤1·주기) ③ 범위 변환(2배·+1·대칭 7−x) ④ 추가 국소 조건(f(3) 홀수·f(2)+f(5)=7) ⑤ 정의역·공역 크기 ⑥ 마지막 질문(개수·특정 함숫값 고정 시 개수·최댓값).

## 5. 세 주제에 공통인 제작 원칙(이번 배치에서 지킬 것)
- 핵심 번역 한 번(불변량·상태 압축·적률·끝값 범위)은 유지하되, **조건의 역할·필수 판단·질문** 중 둘 이상을 바꾼다(KG-A35·제작기록 §제작·검토 범위).
- 경우 수·시행 횟수만 늘려 난도를 올리지 않는다(KG-A03·A18). 최고난도 목표는 '새로 복원해야 할 정보·결합·관점 전환'을 문항별로 적는다.
- 수치는 작게(KG-A32). 객관식은 '값은?' + 5지, 단답형은 1~999 자연수(KG-A33·V11). 확률의 단답형은 p+q(서로소) 또는 N×p 꼴.
- 검산은 전수 열거(NL-05). 조건 삭제 증인(KG-V01), 오개념 풀이의 답(NL-10), 우회 풀이(KG-A17)를 문항마다 기록한다.
- 해설은 KG-S, 용어는 KG-A30(교육과정 ∩ 기출 용어: 독립시행·조건부확률·표본평균·중복조합 허용).
