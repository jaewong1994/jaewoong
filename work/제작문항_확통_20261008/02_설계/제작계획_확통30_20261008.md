## 요청

## 공정
1. 원문 전수 재현(`04_검산/원문_전수검산.py`) → 핵심 구조 분석.
2. 엔진(`04_검산/engines.py`)으로 후보 설계 스캔(`설계_탐색_*.py`) → 답 형식·크기·조건 삭제 증인으로 선별.
3. 확정 검산(`문항_검산_확정.py` → `검산결과.json`): 정답·증인·오개념 답·경고.
4. 원고를 코드(`03_문항/원고_*.py`)로 작성 → `build_manuscripts.py`(형식 검사·JSON·Markdown).
5. 블라인드 검토(문면만, 주제별 독립 전수 검산) → 수정 → 2차(수정분) → 3차(잔여 3건). 기록 `07_검토/검토기록.md`.
6. PDF(`06_출력/build_pdf.py`, KaTeX 로컬 vendor + Noto CJK KR + Chromium).
7. 교훈(`05_교훈/확통_제작_교훈_20261008.md`, 후보 규칙 PS-01~17 + 용어교훈 후보 4).
